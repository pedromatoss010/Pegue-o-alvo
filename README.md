# 🎯 Combo Click

Joguinho web feito com HTML, CSS e JavaScript puro. Clique na bolinha antes do tempo acabar, monte combos e cuidado com a bomba!

## Como jogar

- Clique em **Jogar** para começar.
- Clique na bolinha vermelha para ganhar pontos.
- Acertos seguidos aumentam o seu **combo** e o multiplicador de pontos.
- Clicar fora da bolinha zera o combo e tira 1 ponto.
- De vez em quando a bolinha vira uma **bomba** 💣 — se clicar nela, perde pontos e o combo zera. Ela some sozinha rapidinho, então dá pra evitar.
- Você tem 30 segundos por partida. O recorde fica salvo no navegador.

## Tecnologias

- HTML
- CSS
- JavaScript (vanilla)

## Rodando localmente

Basta abrir o arquivo `index.html` no navegador, ou usar uma extensão tipo *Live Server* no VS Code.
